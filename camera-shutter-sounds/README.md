# Camera Shutter Sounds

Optional downloads for HyperChanger. These are community recordings of the named cameras, not manufacturer-provided sound files. Brand names identify the recorded equipment; no affiliation or endorsement is implied.

The APK contains no preset audio. Each WAV is mono, 44.1 kHz, signed 16-bit PCM with a canonical 44-byte WAV header. A single shutter event was extracted, peak-normalized to -3 dBFS, and given 3 ms edge fades. These short recordings approximate the sound of their source cameras; microphone and recording conditions differ.
